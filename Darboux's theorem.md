State Darboux's theorem for a function $f$ differentiable on an interval $[a, b]$.
#### Notes
If $\alpha$ satisfies $f'(a) < \alpha < f'(b)$ (or $f'(a) > \alpha > f'(b)$), then there exists a point $c \in (a, b)$ where $f'(c) = \alpha$.
