State the theorem linking Riemann's tagged-partition limit to Darboux integrability for a bounded function $f: [a, b] \to \mathbb{R}$.
#### Notes
If $f$ satisfies Riemann's tagged-partition definition on $[a, b]$ with limit $A$, then $f$ is Darboux-integrable on $[a, b]$ and $\int_a^b f = A$.
