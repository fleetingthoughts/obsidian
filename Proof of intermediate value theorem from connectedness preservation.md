Prove: Let $f : [a, b] \to \mathbf{R}$ be continuous. If $L$ is strictly between $f(a)$ and $f(b)$, then there exists a point $c \in (a, b)$ where $f(c) = L$
#### Notes
- Identify $[a, b]$ as a connected set in $\mathbf{R}$.
- Apply the preservation of connected sets to deduce $f([a, b])$ is a connected subset of $\mathbf{R}$, which is necessarily an interval.
- Note that since $f(a), f(b) \in f([a, b])$, any value $L$ strictly between them belongs to the interval $f([a, b])
- Conclude there exists $c \in (a, b)$ such that $f(c) = L$.
