Provide an equivalent characterization of connected sets making use of interval properties of a set
#### Notes
- _Statement:_ A set $E \subseteq \mathbf{R}$ is connected if and only if whenever $a < c < b$ with $a, b \in E$, it follows that $c \in E$ as well.
- _Boundary Conditions and Constraints:_ This property equates connected subsets of $\mathbf{R}$ strictly with bounded or unbounded intervals.
