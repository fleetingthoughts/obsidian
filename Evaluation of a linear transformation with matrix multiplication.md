Let $T:V \to W$ be linear with bases $\beta$ and $\gamma$. State how the coordinate vector of a linear transformation of a vector $T(v)$ can be evaluated by matrix multiplication 
#### Notes
Let $T:V \to W$ be linear with bases $\beta$ and $\gamma$. For each $u \in V$: $[T(u)]_\gamma = [T]_\beta^\gamma [u]_\beta$
