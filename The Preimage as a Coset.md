Let $T: V \rightarrow W$ be linear, $b \in W$, and let $K = \{x \in V : T(x) = b\}$ represent the set of all solutions mapping to $b$. If $K$ is nonempty and contains some particular solution $s$, the entire solution set $K$ can be precisely expressed algebraically in relation to the null space.
