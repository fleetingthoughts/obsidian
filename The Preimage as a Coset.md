Let $T: V \to W$ be a linear transformation and $b \in W$. If $s$ is a particular solution to the linear equation $T(x) = b$, how can the complete solution set $K$ be expressed using $s$ and the null space $N(T)$?
#### Notes
Let $T:V \to W$ be linear, $b \in W$, and $K = \{x \in V : T(x) = b\}$. If $s \in K$, then $K = \{s\} + N(T)$.
