Prove if a diagonalizable matrix $A$ has only one distinct eigenvalue $\lambda$, then $A$ is a scalar matrix.
#### Notes
If matrix $A$ is diagonizable, it is similar to a diagonal matrix $D$, and since it only has one eigenvalue, then $D=\lambda I$ . And so we have: 
$$A = Q(\lambda I)Q^{-1} = \lambda (QIQ^{-1}) = \lambda I$$The converse can easily be proven as these are all equivalence relations.
