Prove that the set $L$ of all limit points of any set $A \subseteq \mathbf{R}$ is closed and use this to prove that the closure of a set $A$ is the smallest closed set that contains $A$.
#### Notes
- Let $x$ be an arbitrary limit point of $L$.
- Prove that every neighborhood $V_\epsilon(x)$ contains a point $y \in L$ (with $y \neq x$).
- Use the fact that $y$ is a limit point of $A$ to show that $V_\epsilon(x)$ also intersects $A$.
- Conclude that $x$ must be a limit point of $A$, thus $x \in L$.
