State the divergence criterion using the monotone convergence theorem
#### Notes
The Monotone Convergence Theorem establishes that a monotonic sequence converges if and only if it is bounded. From this foundation, the divergence criterion for monotonic sequences is stated as follows:
* **Monotonically Increasing Sequences:** If a sequence $(a_n)$ is monotonically increasing (meaning $a_n \le a_{n+1}$ for all $n$) and is **not bounded above**, then it diverges to positive infinity:
$$\lim_{n \to \infty} a_n = +\infty$$* **Monotonically Decreasing Sequences:** If a sequence $(a_n)$ is monotonically decreasing (meaning $a_n \ge a_{n+1}$ for all $n$) and is **not bounded below**, then it diverges to negative infinity:
$$\lim_{n \to \infty} a_n = -\infty$$
