State the Intermediate value theorem.
#### Notes
$f : [a, b] \to \mathbf{R}$ be continuous. If $L$ is a real number satisfying $f(a) < L < f(b)$ or $f(a) > L > f(b)$, then there exists a point $c \in (a, b)$ where $f(c) = L$.
