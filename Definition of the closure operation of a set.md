What is the definition of the closure $\bar{A}$ of a set $A \subseteq \mathbf{R}$
#### Notes
Given a set $A \subseteq \mathbf{R}$, let $L$ be the set of all limit points of $A$. The closure of $A$ is $\bar{A} = A \cup L$.
