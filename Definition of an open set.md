What is the definition of an open set $O \subseteq \mathbf{R}$?
#### Notes
A set $O \subseteq \mathbf{R}$ is open if for all points $a \in O$ there exists an $\epsilon$-neighborhood $V_\epsilon(a) \subseteq O$.
