What are the topological properties of the closure $\bar{A}$?
#### Notes
or any $A \subseteq \mathbf{R}$, the closure $\bar{A}$ is a closed set and is the smallest closed set containing $A$ (meaning if $F$ is any closed set containing $A$, then $\bar{A} \subseteq F$).
