A finite set of vectors $S = \{u_{1}, u_{2}, \dots, u_{n}\}$ is linearly dependent if and only if either the first vector $u_{1} = 0$, or there exists some subsequent vector $u_{k+1}$ that falls within the span of its predecessors, $\text{span}(\{u_{1}, u_{2}, \dots, u_{k}\})$, for some index $k < n$
