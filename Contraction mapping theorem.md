State the Contraction mapping theorem for a function $f : \mathbf{R} \to \mathbf{R}$
#### Notes
If $f$ is a contraction mapping on $\mathbf{R}$, then $f$ has a unique fixed point $y \in \mathbf{R}$ such that $f(y) = y$, and for any arbitrary starting point, the iteration sequence converges to $y$
