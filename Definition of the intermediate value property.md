State the definition of the intermediate value property for a function $f$ on an interval $[a, b]$.
#### Notes
For all $x < y$ in $[a, b]$ and all $L$ between $f(x)$ and $f(y)$, there exists a point $c \in (x, y)$ such that $f(c) = L$.
