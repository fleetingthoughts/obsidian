State the alternative characterization of differentiability for a function $h : A \to \mathbf{R}$ at $a \in A$ involving a continuous function $l$.
#### Notes
$h$ is differentiable at $a \in A$ if and only if there exists a function $l : A \to \mathbf{R}$ continuous at $a$ satisfying $h(x) - h(a) = l(x)(x - a)$ for all $x \in A$, in which case $l(a) = h'(a)$.
