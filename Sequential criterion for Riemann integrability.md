State the sequential partition criterion for a bounded function $f: [a, b] \to \mathbb{R}$ to be Riemann-integrable.
#### Notes
$f$ is integrable on $[a, b]$ if and only if there exists a sequence of partitions $(P_n)_{n=1}^\infty$ of $[a, b]$ such that $\lim_{n \to \infty} [U(f, P_n) - L(f, P_n)] = 0$.
