Prove the cancellation law using the vector space axioms
#### Notes
- Assume $x + z = y + z$.
- By the additive inverse axiom, introduce the inverse $v$ such that $z + v = 0$.
- Write $x = x + 0 = x + (z + v)$.
- Apply associativity to regroup as $(x + z) + v$.
- Substitute the hypothesis to get $(y + z) + v$, then re-associate to yield $y + (z + v) = y + 0 = y$.
