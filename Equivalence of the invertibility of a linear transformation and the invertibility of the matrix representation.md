State the required property of the matrix representation of a linear transformation for it to be equivalent to a linear transformation being invertible.
#### Notes
$T: V \to W$ is invertible if and only if $[T]_\beta^\gamma$ is invertible. Furthermore, $[T^{-1}]_\gamma^\beta = ([T]_\beta^\gamma)^{-1}$.
