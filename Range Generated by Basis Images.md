State a set of vectors that spans the range.
#### Notes
If $\beta = \{v_1, v_2, \dots, v_n\}$ forms a basis for a vector space $V$, then the range of a linear transformation $T$ is strictly generated by the images of that basis, expressed formally as $R(T) = \text{span}(T(\beta))$
