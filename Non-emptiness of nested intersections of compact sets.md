What does the Nested Compact Set Property state regarding infinite intersections? 
#### Notes
If $K_1 \supseteq K_2 \supseteq K_3 \supseteq \dots$ is a nested sequence of nonempty compact sets, then the intersection $\bigcap_{n=1}^\infty K_n$ is not empty. Technically only $K_1$ is compact and the rest just need to be closed.
