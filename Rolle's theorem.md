State Rolle's theorem for a function $f : [a, b] \to \mathbf{R}$.
#### Notes
If $f$ is continuous on $[a, b]$, differentiable on $(a, b)$, and $f(a) = f(b)$, then there exists a point $c \in (a, b)$ where $f'(c) = 0$.
