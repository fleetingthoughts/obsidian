Prove: If $f$ and $g$ are differentiable on an interval $A$ and satisfy $f'(x) = g'(x)$ for all $x \in A$, then $f(x) = g(x) + k$ for some constant $k \in \mathbf{R}$.
#### Notes
- Define $h(x) = f(x) - g(x)$ on the interval $A$.
- Differentiate $h$ to get $h'(x) = f'(x) - g'(x) = 0$ for all $x \in A$.
- Apply the property that a zero derivative on an interval implies a constant function to conclude $h(x) = k \implies f(x) = g(x) + k$.
