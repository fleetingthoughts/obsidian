Prove: In an inner product space, $\langle x, 0 \rangle = 0$.
#### Notes
$\langle x, 0 \rangle = \langle x, 0 + 0 \rangle = \langle x, 0 \rangle + \langle x, 0 \rangle$. Subtracting $\langle x, 0 \rangle$ from both sides yields $\langle x, 0 \rangle = 0$.
